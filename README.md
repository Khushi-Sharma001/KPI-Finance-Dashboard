# KPI Finance Dashboard

## Overview
The KPI Finance Dashboard is an interactive Power BI project designed to monitor and analyze key financial metrics. It provides insights into actual vs target performance, variance analysis, YTD tracking, and team-wise financial performance through dynamic visualizations and KPI indicators.

This dashboard helps organizations make data-driven financial decisions by identifying performance gaps and tracking business progress efficiently.

---

## Features
- Total Sales Actual vs Target comparison
- Variance and variance percentage analysis
- Year-to-Date (YTD) performance tracking
- Team-wise filtering and analysis
- Salesperson performance monitoring
- Monthly financial trend analysis
- Interactive KPI cards and visual reports

---

## Dashboard Insights
- Total Sales Actual: $5M
- Total Sales Target: $5M
- Variance: ($37K)
- Variance Percentage: 0.7%
- Targets achieved in 2 out of 14 months
